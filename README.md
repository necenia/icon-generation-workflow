# Генерация серий иконок

Открой эту папку в агенте и дай ему ссылку на макет либо опиши, где будут стоять иконки. Вход для агента — [AGENTS.md](AGENTS.md).

## Запуск

1. Скопируй [короткий бриф](examples/brief.md) в чат и подставь свои категории, стиль и размер в макете.
2. Выбери направление из предложений агента после поиска референсов.
3. Отметь удачные ячейки сетки координатами, например R1C2. Агент подготовит крупные рендеры и превью в макете.

На выходе будут референсы со ссылками, промпт и общая сетка, отдельные PNG и ссылка на макет или комплект для ручной вставки. Для первого прохода заложи около 20–40 минут после подключения генератора. Перегенерации и согласование идут отдельно.

Для генерации нужен Figma MCP с доступом на запись и кредитами либо подключённый Imagine MCP. Для вставки в Figma укажи ссылку на фрейм. Без генератора можно пройти поиск, разработку направления и подготовку промптов.
