# Запросы агенту по шагам

Копируй нужный запрос. Подставь свои данные в квадратных скобках. Для запуска целиком возьми [короткий бриф](brief.md).

1. **Референсы.** «Для [категории и экран] предложи 2–3 направления. Приложи ссылки, объясни, что взять из референсов, и предложи образ для каждой категории. Порекомендуй одно направление».
2. **Промпт.** «Напиши промпт под [выбранное направление] и карту сетки 3×3. Зафиксируй палитру, материалы, ракурс, свет и поля. Свободные ячейки используй для альтернатив».
3. **Сетка.** «Сгенерируй одну пробную сетку через [Figma MCP / Imagine MCP]. Покажи результат, проверь читаемость в [размер] и предложи лучшие ячейки по координатам».
4. **Клоуз-апы.** «Перерендери [координаты и предметы] отдельно по кропам. Сохрани силуэт, детали и общий свет. Экспортируй PNG с прозрачностью и проверь края».
5. **Макет.** «Поставь PNG в [ссылка на фрейм]. Проверь визуальный масштаб и поля. Покажи скриншот или верни карту размещения для ручной вставки».

Для сравнения стилей: «Перепиши промпт под [новый референс]. Сохрани палитру и карту ячеек. Поясни, что поменялось в форме, материалах, ракурсе и свете».
